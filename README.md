# وب‌سایت خدمات صنعتی محمدی‌نیا

نسخه اولیه یک وب‌سایت تک‌صفحه‌ای فارسی با Astro است.

## اجرای محلی

۱. Node.js نصب باشد.
۲. در پوشه پروژه دستور `npm install` اجرا شود.
۳. برای پیش‌نمایش محلی دستور `npm run dev` اجرا شود.
۴. برای ساخت نسخه ایستا دستور `npm run build` اجرا شود. خروجی در `dist/` قرار می‌گیرد.

محتوای خدمات در `src/data/site.ts` نگهداری می‌شود و عکس‌ها در `public/images/` هستند. اطلاعات فنیِ تأییدنشده عمداً در صفحه درج نشده‌اند.
